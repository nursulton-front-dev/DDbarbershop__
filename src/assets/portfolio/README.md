# Работы мастеров

Здесь хранятся исходные фотографии работ мастеров, пронумерованные от 1 до 8.

Для сайта используются JPG-копии `web/1.jpg` — `web/8.jpg`, подключённые
в `src/lib/site-data.ts` в том же порядке. Оригиналы сохранены без изменений.

Новые фотографии можно добавлять в форматах JPG, PNG или WebP.
HEIC и DNG сначала нужно преобразовать в формат для браузера.
После добавления или замены файлов обновите ссылки в `src/lib/site-data.ts`;
автоподключение не настроено.
